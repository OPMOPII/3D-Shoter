# NEON STRIKE — 3D Shooter 🎮

لعبة إطلاق نار ثلاثية الأبعاد تعمل في المتصفح مباشرة، مبنية بـ **Three.js** في ملف HTML واحد — بدون أي تثبيت.

## طريقة اللعب
1. افتح `index.html` في المتصفح (أو شغّل سيرفر محلي: `python3 -m http.server` ثم افتح `http://localhost:8000`)
2. اضغط **ابدأ اللعب** — الماوس سيُقفل على الشاشة
3. اصمد أمام موجات الأعداء المتزايدة!

## التحكم
| المفتاح | الوظيفة |
|---------|---------|
| `W A S D` | الحركة |
| الماوس | التصويب |
| زر الماوس الأيسر | إطلاق النار |
| `R` | إعادة التلقيم |
| `Shift` | الجري |
| `Space` | القفز |
| `Esc` | إيقاف مؤقت |

## الميزات
- 🎯 3 أنواع أعداء: عادي، سريع، ودبّاب (Tank) — يظهرون تدريجيًا مع تقدم الموجات
- 🔫 سلاح بـ viewmodel كامل: ارتداد، وميض فوهة، آثار طلقات (tracers)
- ✨ جزيئات انفجار، hit markers، وkill feed
- 🌃 رسوميات: إضاءة ديناميكية، ظلال ناعمة، ضباب، نجوم، وحلقات نيون
- 🔊 مؤثرات صوتية مولّدة برمجيًا (بدون ملفات صوت)
- 📈 نظام موجات مع مكافأة صحة بين الموجات
- 🏥 HUD كامل: صحة، ذخيرة، نتيجة، وموجة

## التقنيات
- Three.js 0.160 (عبر CDN)
- Pointer Lock Controls
- Web Audio API (مؤثرات صوتية إجرائية)
- Canvas Texture (أرضية نيون)
